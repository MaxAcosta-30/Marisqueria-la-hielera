# Fase 4 — Propuesta

Muestra interna: sin cobro. Se usará como base para cotizar a clientes reales.

Paquetes sugeridos para clientes reales (a definir por el estudio):
- **Básico:** esta plantilla con sus datos, colores y fotos; dominio propio.
- **Completo:** Básico + sesión de fotos o diseño de logo + ajustes de diseño propios.
- **Mantenimiento:** cambios de menú y precios mensuales.

Costos recurrentes del cliente: dominio (~$200–400 MXN/año, a su nombre). Hosting: $0 (ver fase 6).
Orientación general, no asesoría legal ni financiera.
